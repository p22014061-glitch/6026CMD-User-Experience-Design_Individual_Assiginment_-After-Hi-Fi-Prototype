# HouseFood React V1 — after Lo-Fi Usability Testing

This version keeps the original HouseFood prototype visual style and applies changes supported by UT1 tester feedback.

## Main V1 improvements
- Expiring Soon moved above Recent Items on Home.
- "See All" is more visible.
- Expiring Soon includes high / medium / low colour priority summary and text labels.
- Shopping List shows quantity.
- Shopping List uses a checklist-style icon instead of a shopping-cart icon.
- Shopping List includes search and visual item cues.
- Checked Shopping List items become lighter with a strikethrough.
- Food Guidance now opens a guidance hub containing Food Storage Guidance and Storage & Expiry Guidance.
- Storage & Expiry Guidance is removed from the Expiring Soon page.
- Delete Food now asks for confirmation and shows a success message after deletion.
- All screens remain 440 × 1060.

## Run
```powershell
npm.cmd install
npm.cmd run dev
```
